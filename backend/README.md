Descripción del proyecto

Esta API simula el backend del proyecto “Alrededor de los EE. UU.” utilizado en el curso de frontend.

Creamos un servidor Express desde cero. Organicé el código en módulos (rutas y controladores).
Consumir datos desde archivos JSON utilizando fs y path.
Devolver respuestas JSON según las rutas solicitadas.
Implementar manejo simple de errores (404).
Configurar ESLint con la guía de estilo Airbnb.
Usar nodemon para ejecutar el servidor con hot reload.
Conectar el proyecto a GitHub.


Tecnologías utilizadas

Node.js
Express.js
Nodemon
ESLint (Airbnb Style Guide)


El servidor estará disponible en:

http://localhost:3000
