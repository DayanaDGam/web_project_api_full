# Around the U.S. - Frontend https://aroundeeuu2026.chickenkiller.com/signin

Esta es la aplicación de frontend desarrollada con **React** y **Vite**. Permite a los usuarios registrarse, iniciar sesión, editar su perfil y compartir fotografías de lugares de los Estados Unidos.

## Tecnologías Utilizadas
* **React**: Biblioteca principal de UI.
* **Vite**: Herramienta de construcción y servidor de desarrollo.
* **React Router**: Gestión de rutas y navegación protegida.
* **Context API**: Manejo del estado global del usuario actual.

## Despliegue y Conexión
* **Dominio**: `https://aroundeeuu2026.chickenkiller.com`
* **API URL**: `https://api.aroundeeuu2026.chickenkiller.com`
* El frontend se sirve como archivos estáticos a través de **Nginx** en una instancia de Google Cloud.

## Scripts Disponibles
* `npm run dev`: Inicia el servidor de desarrollo.
* `npm run build`: Genera la carpeta `dist` para producción.
* `npm run lint`: Ejecuta el linter para mantener la calidad del código.
